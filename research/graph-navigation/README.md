# Telemetry-driven graph navigation experiment

[Codito #72](https://github.com/Entif-AI/Codito/issues/72) owns this finite
research instrument. Rosetta #1671/#1728 own GraphView semantics, #1664 trace
evidence and #1221 projection provenance. No Python graph/heat record here is
an official GraphView, policy, truth artifact or authorization contract.

Run `python -m codito.graph_navigation`. Two authored, non-identical graphs
represent code/AST relationships and operational run/action/observation/review
relationships. Edges explicitly distinguish source facts, derived AST structure
and inferred relationships. Frozen graph facts have their own digest. Navigation
telemetry has a separate digest and cannot create/change source nodes or edges.

Seven cases cover rare decisive evidence, stale hot paths after version change,
copied mistaken priors, a noisy contributor, high-frequency low-value paths,
rights removal and cold start. Seeds 3, 11 and 29 compare random neighborhoods,
dependency traversal, charged lexical-label relevance, pure recency, pure
frequency, decayed/task-qualified reinforcement and scouts/recruitment. There
is no available semantic/vector provider; lexical relevance is explicitly a
different deterministic control, not a claimed semantic-model result.

The toy reinforcement profile supplies a half-life of three fixture time units,
20% exploration and a four-node inspection budget. These are experimental
treatments, not protected production calibration. Only successful same-task,
same-version observations contribute, with one latest observation per source
episode root. Recency/frequency controls deliberately retain stale/copy pressure
so their failure remains observable. Unknown graph nodes cannot become candidates
through heat. Rights filter all strategies before selection or hydration.

Scouts read bounded nodes and return attributed hints. Recruitment counts
source roots separately from scout identities; four copied reports remain one
source root. Claimed usefulness is still a judgment. Root IDs in these synthetic
fixtures are supplied experiment provenance, not a signer/trust-admission proof.
No quorum, popularity or heat value establishes source truth or execution rights.

Metrics retain visited nodes, relationship inspections, exact legal candidate
set/digest, hydrated UTF-8 source bytes, lexical-index bytes and heat-telemetry
bytes. They also include recall, wrong-path/rework proxies, exploration coverage,
cold start, stale-telemetry counts and independent source roots inspected. Search
is instrumented in-memory fixture access. Local wall nanoseconds are measured;
hydration counts are real Python accesses, while external tool/model calls are
zero. These are not measured production token/cost/network savings.

Report harm as well as benefit. Reinforcement may save visits yet require more
telemetry bytes than simpler traversal, fail during cold start, explore a wrong
path, or lose after source change. A fixed finite fixture cannot establish a
general routing advantage. The experiment can reject a treatment without
requiring Rosetta graph changes or biological metaphors in protocol semantics.

Protocol posture: unregistered synthetic experiment, fixed families/failures,
seeds/profile and inspection budget, no sealed holdout or statistical efficacy
claim. Fixture facts/heat and the actual measured run are checked in separately.
