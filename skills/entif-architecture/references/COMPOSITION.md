# Shared capability composition

Compose rather than absorb:

- `entif-feature-design` for UI/UX.
- `entif-axi` for AXI suitability and upstream `axi-axi` scaffold/validation.
- `rosetta-spine-alignment` for Rosetta semantic alignment.
- `entif-work-orchestrator` and `entif-feature-workflow` for executable branch work.
- `entif-pr-closeout` for final PR/review/archive/merge evidence.
- `create-verification-skill` / `maintain-verification-skill` for real-product verification harnesses.
- `autopilot` for autonomous work selection/execution.
- `show-me-your-work` for reviewable decision trails.
- `entif-governed-creator` for Skill mutation governance.
- `entif-work-stack`, `entif-run-durability`, and `entif-session-continuity` for runtime durability/continuity.
- runtime/model orchestration (including Swarm/Fable-like execution doctrine) from its canonical owner.
