# Experimental project Skills

Codito versions experimental Entif/Rosetta Skill sources without becoming public Rosetta semantic authority.

- `entif-architecture/`: compact Chat-first architecture meta-skill with deep progressive disclosure.
- `entif-axi/`: governed AXI-first agent-interface capability composing upstream `axi-axi`.
- `entif-runtime/`: capability-aware durable-execution meta-skill for continuity, checkpoints, recovery, Work Stack state, context pressure, and failure intelligence across execution surfaces.

Installed old entrypoints may remain active until parity, rollback, and routing telemetry gates are satisfied.
